## Resumo do Projeto
Este projeto consiste num website temático baseado na série *Gossip Girl*, desenvolvido como o meu primeiro projeto pessoal de desenvolvimento web. O objetivo principal foi criar uma interface visualmente fiel à estética da "Elite de Manhattan", apresentando perfis de personagens icónicos como Blair Waldorf, Serena van der Woodsen e Dan Humphrey.

## Tecnologias Utilizadas
* **HTML5**: Utilizado para a estruturação semântica de todo o conteúdo do site.
* **CSS3**: Aplicado para a estilização visual, incluindo layouts, cores e tipografia personalizada.
* **Tipografia Customizada**: Integração de fontes específicas como a *Helvetica Neue* (em diversas variações como Black, Bold e Light) para replicar a identidade visual da série.

## Estrutura do Sistema
O projeto está organizado da seguinte forma:
* **index.html**: Ficheiro principal contendo a estrutura da página de destino e as secções dos personagens.
* **style.css**: Folha de estilos que define o design responsivo e a estética do blog.
* **Pasta dist/img/**: Repositório de assets visuais, incluindo as fotos dos personagens e os ficheiros de fontes.

## Aprendizados e Desenvolvimento
Sendo este o meu primeiro projeto prático no desenvolvimento front-end, os principais focos de aprendizagem foram:
* **Fundamentos de Web Design**: Compreensão de como converter um conceito visual numa estrutura de código funcional.
* **Tratamento de Imagens e Assets**: Organização e referência de media dentro de um projeto web.
* **CSS Typography**: Implementação de @font-face para utilizar fontes locais e garantir a consistência do design.

## Como Executar
Para visualizar o projeto localmente:
1.  Faça o download ou clone o repositório.
2.  Navegue até à pasta `dist`.
3.  Abra o ficheiro `index.html` em qualquer navegador web moderno.
